How the signal rules work

  • BUY: fast SMA above slow SMA, latest close above fast SMA, and RSI confirms upward momentum.
  • SELL: fast SMA below slow SMA, latest close below fast SMA, and RSI confirms downward momentum.
  • WAIT: rules conflict, data is insufficient, or RSI is outside the confirmation range.

This is a technical-indicator rule set, not a prediction guarantee. Test on historical/demo data before relying on it.
